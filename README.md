A modern workout tracking app built with Flutter.

⚠️ This repository is a showcase of the project.
The full source code remains private while the application is under active development for a future Play Store release.

---

## Highlights

- 📱 Built with Flutter
- 🎓 Graduation Project (Software Engineering)
- 🎨 UI designed from scratch in Figma
- 🧩 Component-based architecture
- ⚡ State management with Riverpod
- 🛣️ Navigation with GoRouter
- 📐 Design System implementation
- 🚧 Currently under active development
